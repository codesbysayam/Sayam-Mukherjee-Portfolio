## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Local Development
```bash
# Clone the repository
git clone https://github.com/codesbysayam/Sayam-Mukherjee-Portfolio.git
cd Sayam-Mukherjee-Portfolio

# Install dependencies
npm install

# Start the local development server (port 3000)
npm run dev
```

### Production Build
```bash
# Compile client and server bundles
npm run build

# Start the production server
npm run start
```
